# Java Backend Engineering Labs

A collection of hands-on experiments for learning advanced Java, backend engineering, distributed systems, and system design.

This repository supports the development of EventFlow, a distributed order and payment processing platform.

## Technology Stack

- Java 21
- Maven Multi-module
- JUnit 5

## Modules

| Module | Description |
|---|---|
| 01-concurrency | Java concurrency and multithreading fundamentals |

## Build and Test

```bash
mvn clean test
```

## Learning Approach

Understand the theory, implement solutions, test behavior, investigate failures, and apply the knowledge to EventFlow.
